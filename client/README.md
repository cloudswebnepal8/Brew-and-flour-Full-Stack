# Brew & Flour — Client (React + Vite)

This is the frontend only. See the top-level `README.md` (one folder up)
for full instructions on running this together with the `server/` API.

Quick start:
```bash
npm install
npm run dev
```
Requires the backend (`../server`) running on port 3001 for reservations,
contact, newsletter, menu, and gallery data to work live — otherwise the
menu/gallery pages fall back to bundled sample data.
